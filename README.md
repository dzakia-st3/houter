# Houter Landing Page 🏡

A clean and responsive landing page designed to showcase a platform for finding places to live, such as houses, apartments, or villas.

This project focuses on creating a visually appealing layout and smooth user experience, with well-structured sections and responsive design.

## 🚀 Live Demo

https://houter-react-typescript.netlify.app/

## 🛠 Tech Stack

* React
* TypeScript
* Tailwind CSS

## ✨ Features

* Responsive layout for different screen sizes
* Clean and modern UI design
* Property recommendation sections
* Testimonials and article sections
* Subscription form (UI only)

## 📌 Notes

This is a static landing page project focused on UI/UX and layout implementation. No backend or dynamic data is used.

## 📂 Getting Started

```bash id="kx9s2l"
npm install
npm start
```
